# quant-lab-01

M1 结项：贵州茅台（600519）双均线策略回测。

## 目标

用 akshare 拉真实行情，用 pandas 走通一个最小可用的量化闭环：

1. 取数 → 清洗 → 落盘 CSV
2. 算 MA5 / MA20 并画图
3. 回测「MA5 在 MA20 上方持仓，否则空仓」
4. 用 `.shift(1)` 消除未来函数
5. 计入佣金、印花税、滑点
6. 用 Git 管理版本，打 tag 结项

## 数据

- 标的：贵州茅台 600519（上交所主板）
- 区间：2024-01-02 – 2024-12-31，共 **242 个交易日**
- 复权：**前复权（qfq）**，已核对 2024 年 6 月除权日前后无异常跳空
- 来源：**akshare** `stock_zh_a_hist`（底层东方财富）
- 文件`600519_daily.csv`（12 列：日期、股票代码、开盘、收盘、最高、最低、成交量、成交额、振幅、涨跌幅、涨跌额、换手率）

## 方法

- 信号`MA5 > MA20` → 1（持仓），否则 0（空仓）
- 执行`pos = signal.shift(1)`，**T+1**，今天收盘算信号、明天才生效
- 收益`strategy = pos * 收盘.pct_change()`
- 费用参数：

| 项 | 费率 | 方向 |

|---|---|---|

| 佣金 | 0.025% | 买卖双边 |

| 印花税 | 0.05% | 仅卖出 |

| 滑点 | 0.05% | 单边 |

| **合计** | **买入 0.075% / 卖出 0.125%** | — |

- 复现`python ma.py` → `python strategy.py` → `python cost.py`

## 结果

| 指标 | 数值 |

|---|---|

| 策略累计收益（不含费） | **-23.34%** |

| 策略累计收益（含费） | **-24.61%** |

| 买入持有累计收益 | **-6.85%** |

| 未来函数虚增 | **+21.19 pp** |

- 调仓 17 次（买 9 / 卖 8），持仓 95 / 242 天
- 费用拖累 1.27 pp，占总亏损 5.2%

## 失败点

1. **样本只有 1 只股票、1 年**：600519 × 2024 × 242 个交易日，横截面上无法做因子研究，结论不能外推到其他股票或市场状态。
2. **均线是滞后指标**：MA20 需要 20 个交易日才有值，信号天然滞后；2024 年该策略调仓 17 次、跑输买入持有 16.48 pp（由未舍入值计算），是震荡市里被反复 whipsaw 的直接证据。
3. **用收盘价成交，实盘做不到**：信号在收盘后才算出，实际只能次日开盘或盘中成交；0.05% 的滑点假设偏乐观，且未模拟涨跌停与停牌导致无法成交的情形。
4. **用当前成分股回测历史 = 幸存者偏差**：沪深 300 成分股每半年调整一次，本项目取的是当前（2026-11）成分名单；用它回测 2024 年，等于提前知道"哪些股票能活到今天且留在指数里"，会系统性高估收益。正确做法是使用时点成分股（point-in-time），或改用全市场股票池。
